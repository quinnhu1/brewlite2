# Yêu cầu sản phẩm

Lưu SRS, phạm vi, stakeholder, user story, tiêu chí chấp nhận và đặc tả use case của nhóm tại đây. Dùng cùng mã yêu cầu trong tài liệu, sơ đồ và [ma trận truy vết](../traceability-matrix.md).

Luồng hiện có đi từ menu qua chọn size và topping, giỏ hàng, xác thực, tạo đơn, thanh toán và xác nhận. Phạm vi sprint và tiêu chí chấp nhận do nhóm thống nhất trong Task 1.
